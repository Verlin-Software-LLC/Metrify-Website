# Metrify marketing site

Static pages, no build step. Open `index.html` in a browser.

## Pages

- `index.html` : landing page
- `faq.html` : frequently asked questions
- `articles/` : articles section (`articles/article.css` is the shared stylesheet)
- `privacy.html` : Privacy Policy
- `terms.html` : Terms of Service
- `delete-account.html` : account deletion instructions
- `sitemap.xml`, `robots.txt`

## Notes

- Typography: Archivo Black (display) and Archivo (body), loaded from Google Fonts.
- Brand orange is `#FF7A00` on dark.
- Contact: `support@metrify.fit`.
